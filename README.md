## PS4 schematic archive

`ps4-schematic-archive/` holds the full extraction of the PS4 Slim **ADP-160CR** power-supply
schematic, with enlarged/annotated images, a redrawn block diagram and a component reference.

Open `ps4-schematic-archive/index.html` (or run
`python3 -m http.server 8099 --directory ps4-schematic-archive`) to browse it.
